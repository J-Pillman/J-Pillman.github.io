# Digital Shield (CyberShield)

Landing page para que adultos mayores verifiquen mensajes, enlaces y llamadas sospechosas.
Proyecto del curso HCI for UX Design (UPC, 2026-20). HTML, CSS y JavaScript puros.

## Estructura
- `pages/index.html`: landing page.
- `css/styles.css`: estilos (responsive con media queries).
- `js/main.js`: interacciones y reglas de detección.
- `assets/`: logotipo (`images/`) y escudo (`icons/`).
- `favicon.ico`: escudo de Digital Shield.
- `docs/`: documentación.

## Nota
El análisis usa reglas en JavaScript (no una API de IA). Los datos de ejemplo son ficticios.
